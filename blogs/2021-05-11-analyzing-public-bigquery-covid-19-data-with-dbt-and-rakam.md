In an effort to help combat COVID-19, Google has created a COVID-19 public datasets program to make data more accessible to researchers, data scientists, and analysts. This data is available in the BigQuery platform and can be reached by using this link. For my analysis, I have chosen to work with the covid19_open_data dataset since it is very rich containing more than 500 columns of data.
